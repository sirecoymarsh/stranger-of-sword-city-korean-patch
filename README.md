# Stranger of Sword City 한국어 패치 v1.5

일본어판 슬롯을 한국어 슬롯으로 교체하는 비공개 배포용 패치입니다. 의미 기준 원문은 일본어판이며 공식 영문판은 문맥 교차 확인에만 사용했습니다.

## 추가·변경 사항

이 패치는 Stranger of Sword City(스팀 PC판, 앱 ID 409890)의 **일본어 언어 슬롯을 한국어로 바꿔치기**하는 방식입니다. 영어 슬롯은 그대로 두고, 일본어 슬롯이 쓰는 파일과 두 언어가 함께 쓰는 실행 파일·글꼴·그래픽 일부를 고칩니다. 아래 내용은 커밋(`64bf906`~`69ecb51`), 릴리스 노트(`v1.0`·`v1.1`·`v1.2`·`v1.5`), 설치 스크립트와 `manifests/` 기록을 근거로 정리했습니다.

### 번역 범위

- **번역 원문**: 일본어판을 의미 원문으로 삼고, 공식 영어판은 문맥 교차 확인에만 썼습니다(`manifests/language_contract.json`, `manifests/style_guide.md`).
- **번역한 곳**(v1.5 기준 20,427개 항목, `manifests/language_qa.json`):
  - 이벤트 스크립트 대사(`event/Script.dat`) 10,555개
  - 데이터 테이블(아이템·스킬 설명, 메뉴 문구 등, `table/tablePack.dat`) 3,792개
  - 튜토리얼·도움말(`help/tutorial.dat`) 575개
  - 실행 파일에 박혀 있던 UI 문구(`StrangerOfSwordCity.exe`) 1,470개
  - v1.5에서 새로 찾아 번역한 실행 중 표시 문구 4,035개: NPC 이름 1,593개, 스킷(짧은 대화극) 1,048개, 여러 개 선택지 694개, 단일 선택지 422개, 도움말 창 제목 278개
- **그림 글자**: 타이틀 화면(`graphic/title.exg`, 부제 「검의 도시의 이방인」), 지도 UI 배경(`graphic/comTex/mapicBG.exg`), 초반 주의 문구 그림(`graphic/ev/ev_020.exg`, 추정)을 한국어로 바꿨습니다.
- **영상 자막**: 일본어 오프닝 영상 4개(`graphic/soa_op.wmv`, `soa_op_h.wmv`, `soa_op_off.wmv`, `soa_op_h_off.wmv`)의 자막을 한국어로 바꿨습니다. `_h`·`_off`가 붙은 판의 차이(해상도·자막 유무 등)는 기록에 없습니다(추정).
- **일부러 원문을 남긴 곳**:
  - 타이틀 메뉴 `New Game` / `Option` / `Load Data` / `Exit` 네 개는 영어 그대로입니다. 원판이 선택·비선택 상태를 다른 방식으로 그려서, 한글로 바꾸면 두 상태의 모양이 어긋나기 때문입니다(`v1.0` 릴리스 노트).
  - 선택지 화면 머리글 `SELECT / Verum cur non audimus?`는 원판이 의도한 라틴어라서 그대로 둡니다(`graphic/comTex/comtex.exg`는 패치에 넣지 않음, `manifests/release_qa.json`).
  - 영어 슬롯의 `_E` 파일(`Script_E.dat`, `tablePack_E.dat/.hed`, `tutorial_E.dat`)은 바이트 단위로 같게 보존합니다(`manifests/english_preservation.json`).
- **용어·문체**(`manifests/style_guide.md`): 이방인, 이방인 길드, 에스카리오, 혈통종, 영혼의 그릇, 전열·후열, 직업명(파이터·나이트·사무라이·위저드·클레릭·레인저·닌자·댄서) 등을 고정했습니다. 대사는 인물 관계에 맞는 구어체, 시스템·UI는 짧은 해요체나 명사형입니다. v1.2에서 `剣の街` → 검의 도시, `陰の王宮` → 그림자 왕궁, `地下死街` → 유령 도시, `純血晶` → 혈정, `軽刃`/`重刃` → 경검/중검으로 바로잡았습니다.
- **번역 방식**: 최종 번역에 구글 번역이나 외부 기계번역은 쓰지 않았고, Codex가 일본어 원문과 게임 안 문맥을 직접 검수했다고 기록돼 있습니다(`manifests/language_qa.json`).
- **바꾸지 않은 것**: 아이템 수치(`item.dat` 스탯 영역)는 0건 변경입니다(v1.1·v1.2 릴리스 노트).

### 편의 기능

- **한글 이름 입력**(v1.5): 원판에는 없던 한글 IME 입력을 지원합니다. 입력한 한글을 CP949로 바꿔 받고, 빈 입력에서 멈추지 않도록 막았습니다(`manifests/semantic_manifest.json`의 `runtime_fixes`).
- **한국어 종료 확인 창**(v1.5): 게임을 끌 때 뜨는 확인 대화상자를 유니코드 한국어로 띄웁니다.
- 되감기·빠른 스킵·자동 진행 같은 진행 편의 기능은 추가하지 않았습니다.

### 단축키·조작

- 새로 넣은 단축키는 없습니다. 언어는 스팀 **속성 → 언어**에서 **일본어(Japanese)**, 게임 안 **Options → Language**에서 **Japanese** 자리를 고르면 한국어로 나옵니다.

### 화면·글꼴

- **한글 글꼴**: 게임 글꼴(`fontdata/fontdata01.exp`, `fontdata02.exp`)에 한글 글리프를 넣고, Shift-JIS↔유니코드 변환표(`table/sjis2uni.tbl`, `table/uni2sjis.tbl`)를 고쳐 일본어 문자 자리에 한글을 배정했습니다. v1.0·v1.1은 번역문에 쓰인 글자만(1,109자 → 1,107자) 넣었고, v1.5부터는 **완성형 한글 11,172자 전부**를 매핑해 이름 입력 등에서 어떤 글자를 써도 나오게 했습니다. 영어 글꼴 문자 18,496개와 겹침은 0건입니다(v1.0 `runtime_verification.json`).
- **선택지 표시**(v1.5): 선택지 두 개가 동시에 보이도록, 세로 균형과 아래쪽 선택지의 가운데 정렬을 고쳤습니다(`table/layout.lod` 추가).
- **오프닝 영상**(v1.5): 한국어 자막을 넣은 오프닝을 게임이 재생할 수 있는 WMV3 형식으로 다시 인코딩했습니다.
- 해상도·와이드·전체화면 설정은 바꾸지 않았습니다.

### 버그 수정

- **초반 붉은 경고 패널 배치**(v1.0): 한국어로 바꾸면서 어긋나던 경고 패널 배치를 고쳤습니다.
- **v1.1의 과잉 교정·용어 불일치**(v1.2): 고유명사·지명 표기 되돌림, 수배 목록 조사(은/는, 이/가) 오류 5건, 인명 불일치를 포함해 185행을 고쳤습니다.
- **글리프 캐시 넘침으로 인한 충돌**(v1.5): 한글을 입력하거나 스킷이 진행될 때 실행 파일이 멈추던 문제를 막았습니다. 적용 후 13.7분 연속 플레이에서 충돌 기록(WER/덤프)이 없었습니다.
- **`가` 경계 글리프**(v1.5): 한글 영역의 첫 글자인 `가`의 글리프 경계 문제를 고쳤습니다. 이름 입력에서 `가`가 제대로 표시되는 것을 확인했습니다(증상은 추정: `가`가 깨지거나 빠짐).
- **선택지 겹침**(v1.5): 성별에 따라 갈리는 같은 선택지가 겹쳐 정렬이 틀어지던 문제를 고쳤습니다(`duplicate gender-variant alignment`).
- **이전 판에서 빠진 번역**(v1.5): NPC 이름, 선택지, 도움말 창 제목, 스킷 대사 4,035개를 새로 번역했습니다.
- 원판 자체의 버그를 고쳤다는 기록은 없습니다.

### 설치·제거 방식

- **고치는 파일(v1.5, 17개)**: `StrangerOfSwordCity.exe`, `event/Script.dat`, `fontdata/fontdata01.exp`, `fontdata/fontdata02.exp`, 오프닝 영상 4개, `graphic/title.exg`, `graphic/comTex/mapicBG.exg`, `graphic/ev/ev_020.exg`, `help/tutorial.dat`, `table/sjis2uni.tbl`, `table/uni2sjis.tbl`, `table/tablePack.dat`, `table/tablePack.hed`, 새 파일 `table/layout.lod`. 차분 파일이 아니라 패치된 파일 전체를 넣어 교체합니다.
- **원본 확인**: 설치 전에 17개 파일의 원본·패치 SHA-256과 패키지 전체 목록(`manifests/package_manifest.json`)을 확인합니다. 지원하지 않는 판, 원본과 패치가 섞인 상태, 변조된 파일이 있으면 아무것도 쓰기 전에 멈춥니다. 게임 프로세스(`StrangerOfSwordCity`)가 실행 중이어도 멈춥니다.
- **게임 폴더 자동 탐색**(v1.5, `0ba66b1`): 레지스트리의 스팀 경로, 기본 스팀 폴더, 각 드라이브의 `SteamLibrary`·`Steam` 폴더, `libraryfolders.vdf`의 라이브러리 목록을 차례로 찾아봅니다. 못 찾으면 `-GameRoot`로 지정합니다.
- **백업**: 게임·패치 폴더 바깥인 `문서\Stranger of Sword City Korean Patch Backups`에 원본과 패치 복구본을 보관합니다(`-BackupRoot`로 변경 가능). 교체는 트랜잭션 방식으로 하고, 중간에 끊겨 섞인 상태도 백업 기록으로 되돌릴 수 있습니다.
- **제거**: `Restore-Original.ps1`이 가장 최근의 유효한 백업으로 원본을 되돌립니다. `-BackupPath`로 특정 백업을 고를 수 있습니다.
- **판 올리기**: 이전 판이 깔려 있으면 **그 판의** `Restore-Original.ps1`로 먼저 원본을 되돌린 뒤 새 판을 설치해야 합니다(덮어쓰기 설치 불가).
- **지원 판본**: 스팀판만 확인했습니다. GOG 등 다른 판은 해시가 다르면 설치가 거부됩니다.

### 알려진 문제

- 게임 끝까지의 전체 플레이와 후반 화면은 아직 확인하지 않았습니다(`manifests/runtime_verification.json`).
- 라틴어 머리글 원본 복구는 해시로만 확인했고, 복구 뒤 게임을 다시 실행해 보지는 않았습니다.
- 배포 압축 파일의 Windows Defender 검사는 하지 못했습니다(`release-metadata.json`).
- v1.1·v1.2는 게임을 실행하지 않은 정적 검증판이라, 실제 화면 문제는 v1.5에서야 확인·수정됐습니다.

## 설치

1. 게임을 종료합니다.
2. 압축을 푼 폴더에서 다음 명령을 실행합니다.

   ```powershell
   powershell.exe -ExecutionPolicy Bypass -File .\Install-KoreanPatch.ps1
   ```

3. Steam **속성 → 언어**에서 **일본어(Japanese)**를 선택합니다.
4. 게임 내 **Options → Language**에서도 Japanese 위치를 선택하고 **Apply**한 뒤 다시 시작합니다.

설치기는 Steam 라이브러리에서 게임을 자동 탐색합니다. 찾지 못하면 다음처럼 지정합니다.

```powershell
.\Install-KoreanPatch.ps1 -GameRoot 'D:\SteamLibrary\steamapps\common\Stranger of Sword City'
```

설치 전 패키지 전체 인벤토리와 원본·패치 SHA-256을 확인합니다. 지원하지 않는 버전, 원본·패치 혼합 상태, 변조 파일은 쓰기 전에 거부합니다. 백업은 게임 및 패치 폴더 바깥의 문서 폴더에 생성됩니다.

## 검증과 복구

```powershell
.\Verify-KoreanPatch.ps1
.\Restore-Original.ps1
```

기존 패치가 설치되어 있으면 **해당 판의** `Restore-Original.ps1`로 먼저 원본을 복구한 뒤 v1.5를 설치하십시오.

## 검증 범위

- 번역 맵 20,427개 UID, 원본 해시 17개, 패치 해시 17개
- 사용자 확인: 시작 진행, 한글 이름 입력, NPC 이름, 스킷, 2개 선택지 표시와 정렬
- 13.7분 연속 플레이에서 WER/크래시 덤프 없음
- 최종 라틴어 머리글 복구는 원본 해시·바이트로 정적 확인
- 전체 후반 플레이스루는 아직 완료하지 않음

세부 해시와 범위는 `manifests` 폴더를 참조하십시오.
